# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server or external dependencies.
- Preserve the existing visual style, responsive layout, and light/dark theme support.
- Keep interactions keyboard-accessible and provide appropriate semantics and feedback for assistive technology.
- Respect `prefers-reduced-motion` when adding animations.
- After changing the quiz, open `index.html` in the integrated browser and verify the affected interaction or display.
